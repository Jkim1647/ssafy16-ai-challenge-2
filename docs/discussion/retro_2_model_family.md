1편에서 35B와 397B를 섞으니 점수가 올랐다고 말씀드렸습니다. 그 뒤로 저희는 앙상블에 넣을 모델을 계속 찾았습니다.

### Qwen만 쓰다가 막혔다

처음에는 Qwen 계열만 썼습니다. 9B, 27B, 35B, 122B, 397B, 그리고 3.8까지요. 모델을 바꾸고 키워도 앙상블 점수는 잘 오르지 않았습니다.

그때 팀원 윤석웅 님이 **Gemma 4 31B**를 가져왔습니다. 단독 성능은 Qwen과 비슷했는데, 대회 데이터로 학습시켜 앙상블에 넣었더니 점수가 조금 올랐고 최종 제출까지 들어갔습니다. 저희도 자연스럽게 이렇게 생각했습니다.

> "역시 다른 회사 모델이라 틀리는 문제가 달라서 도움이 되는구나."

그런데 대회를 정리하면서 이걸 실제로 재 봤더니, **틀린 생각**이었습니다.

### 재 보니: 집안은 상관없었다

검증셋 667문제에서 모델 8개를 두 개씩 짝지었습니다. 그리고 "둘 중 하나라도 틀린 문제 중에 둘 다 틀린 비율"(오답 겹침)을 계산했습니다. 숫자가 낮을수록 서로 다르게 틀린다는 뜻입니다.

![모델 간 오답 겹침](IMAGE_1)

- **Gemma ↔ Qwen은 0.489, Qwen ↔ Qwen은 0.465입니다.** Gemma가 Qwen과 특별히 다르게 틀리지 않았습니다. 오히려 조금 더 겹쳤습니다.
- 진짜로 갈린 건 **"추가 학습을 했느냐"** 였습니다. 학습한 모델과 그대로 쓴 모델을 짝지으면 0.446으로 가장 덜 겹쳤습니다.
- 가장 많이 겹친 쌍(0.65)은 같은 크기에 같은 데이터로 같은 방식으로 학습한 27B 두 개, 그리고 추가 학습 없이 쓴 35B와 122B였습니다.
- 앙상블에서 Gemma를 빼 봤더니 검증셋에서 2문제가 줄었습니다. 다른 멤버를 뺄 때와 비슷한 수준이었습니다. Gemma는 "다른 집안이라서"가 아니라 **그냥 잘 학습된 좋은 모델 하나**로서 도움이 된 것이었습니다.

### 그래서 앙상블 멤버를 고를 때는

1. **계열보다 "어떻게 만들었나"를 섞으세요.** 추가 학습한 모델과 그대로 쓴 모델을 함께 넣을 때 가장 서로를 보완했습니다.
2. **같은 방식으로 학습한 비슷한 모델 두 개는 하나만 넣으세요.** 저희의 단독 최고 모델(Discussion에서 공유된 "학습할 때 보기 순서 섞기"를 적용한 27B)도 기존 27B와 0.65나 겹쳤습니다.
3. **같은 모델에 프롬프트만 바꾼 버전은 거의 도움이 안 됩니다.** 저희 경우 틀린 문제가 94% 겹쳤습니다(train 6,047문제 기준).
4. **넣기 전에 오답 겹침부터 재 보세요.** 몇 줄이면 됩니다.

```python
# 두 모델의 오답 겹침 (자카드). 1에 가까울수록 같이 넣을 이유가 적다
wrong_a = {i for i in ids if pred_a[i] != gold[i]}
wrong_b = {i for i in ids if pred_b[i] != gold[i]}
overlap = len(wrong_a & wrong_b) / len(wrong_a | wrong_b)
```

"다른 회사 모델을 섞으면 좋다"는 말은 그럴듯하지만, 적어도 이번 대회에서는 재 보니 아니었습니다. 감으로 넣기 전에 한 번 재 보시길 추천합니다.
