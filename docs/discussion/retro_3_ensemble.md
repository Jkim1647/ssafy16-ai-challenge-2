[회고 3] 제출 53번 해 보고 알았다… 앙상블 1등은 결국 '그냥 평균'?!
---
마지막 편입니다. 저희는 53번 제출했고, 그중 절반 이상이 앙상블 실험이었습니다. 점수는 이렇게 올라왔습니다.

### 해 본 방법들

"앙상블 = 평균" 정도로만 알고 시작했는데, 해 보니 방법이 정말 많았습니다.

| 방법 | 한 줄 설명 |
|---|---|
| 확률 평균 | 모델마다 a~d 확률을 내고 그냥 평균 |
| 로그확률 평균 | 확률 대신 로그를 평균(= 기하평균). 한 모델이 확신하면 더 끌려감 |
| 가중 평균 | 모델마다 비중을 다르게. 81가지 조합을 격자로 탐색 |
| 따로 학습한 결합기 | 모델 확률을 입력으로 받아 최종 답을 내는 작은 모델 |
| 순위 투표(Borda) | 확률 대신 1·2·3·4등 순위로 점수 매기기 |
| 절사 평균 | 가장 튀는 모델 하나를 빼고 평균 |
| 다수결 | 모델마다 한 표. 동점이면 순서로 정하거나 확률 합으로 정함 |
| 규칙 기반 보정 | "여러 다수결이 한목소리면 그 답" 같은 규칙 |
| 보기 순서 돌리기 | 보기 순서를 바꿔 다시 묻고 평균(TTA) |

### 결과: 1등은 결국 '그냥 평균'

- 검증셋에서 결합 방법 8가지를 비교해 봤습니다. 데이터를 반으로 나눠 다시 보면 **1등이 계속 바뀌었습니다.** 차이 대부분이 잡음이었다는 뜻입니다.
- 로그확률 평균을 **그냥 확률 평균으로 바꾼 것**이 검증셋과 Public에서 같은 방향으로 오른 몇 안 되는 변화였습니다(Public +3문제).
- 가중치를 81가지 조합으로 찾아 **검증셋 1등을 한 조합은 Public에서 오히려 떨어졌습니다.** 검증셋에 맞춰진 거였죠.
- 다수결은 확률 평균과 비슷하거나 조금 낮았습니다.
- 저희 최고점(0.97706)도 결국 **이미 좋았던 제출 3개와 모델 2개를 똑같은 비중으로 평균**한 것이었습니다.

### Public 점수 차이, 어디까지 믿어야 할까

앙상블을 하다 보면 Public이 1~2문제씩 오르내리는 걸 계속 보게 됩니다. 저희가 쓴 기준은 이렇습니다.

- Public은 test의 절반이라 **1문제가 약 0.0003**입니다.
- 두 제출의 답이 **K개 다르면**, 우연만으로도 약 **±√(K/2)문제**는 흔들릴 수 있습니다.
- 예를 들어 답이 20개 다른 두 제출이 2~3문제 차이 나는 건 "좋아졌다"기보다 운일 가능성이 큽니다.

이 기준보다 작은 차이는 개선으로 치지 않았습니다. 그리고 저희가 만든 검증셋 두 개(test와 같은 방식으로 만든 셋 + 사람이 다시 검수한 어려운 셋)를 **둘 다 통과해야** 채택했습니다. 덕분에 Public에서만 운 좋게 오른 후보를 여러 번 걸러냈습니다.

### 솔직한 반성

마지막 날에는 결국 Public 점수를 보고 제출을 골랐습니다. 최종으로 고른 두 제출은 Public 1·2등이지만, 저희 어려운 검증셋에서는 그 전 기준 제출보다 4문제 낮습니다. 어느 쪽이 맞았는지는 Private이 나오면 댓글로 공유하겠습니다.

### 앙상블 하실 분께 한 가지만

**모델마다 a~d 확률을 꼭 저장해 두세요.** 답 글자만 저장하면 섞을 때마다 모델을 다시 돌려야 합니다. 확률을 저장해 두면 새 조합을 GPU 없이 CPU에서 몇 초 만에 계산할 수 있습니다. 저희가 53번이나 시도할 수 있었던 것도 이 덕분이었습니다.
