# 35B LoRA (A안, 타일 없음) — 27B에 유의하게 밀린다 (2026-09-23)

`shared_predictions/runpod_35b_lora_A/`. RunPod H200 SXM, 약 $6.

## 왜 돌렸나

오늘 train 6,047건에서 두 모델이 **같이 틀리는 144건**을 분류한 결과, 86%가 같은 답으로 틀리고 그중 85건은 양쪽 확신도 ≥0.9였다. 판독문은 정확한데 선택이 달랐다 — 사진에 `소화기`가 적혀 있고 모델이 그대로 읽었는데 정답은 `소화전`인 식이다.

담당 프로 안내대로 정답이 **사람들의 합의**라면, zero-shot 은 원리적으로 이 패턴을 못 배운다. 파인튜닝만이 배울 수 있고, 실제로 27B LoRA 가 val667 단일 1위(0.9685)였다. 그래서 **27B 와 변수 하나(모델 27B→35B)만 다르게** 돌렸다.

## 설정

| 항목 | 값 |
|---|---|
| 모델 | Qwen3.6-35B-A3B (27B dense → 35B MoE, **이것만 변경**) |
| LoRA | r8 / alpha16 / lr 1e-4 / 1 epoch / grad-accum 16 / seed 1 |
| 입력 | `--view full` (타일 없음 — 27B 와 동일) |
| 학습셋 | 5,143건 (holdout1500 과 train_exclusions_v2 71건 제외) |
| 평가셋 | **holdout1500** (val667 포함 상위집합, 이미지 group split) |
| 속도 | 0.47초/샘플, 학습 2,420초 |

## 결과

**holdout1500: 1,424/1,500 = 0.9493** (95% CI 0.9370–0.9593)

val667 부분집합으로 기존 모델과 짝비교:

| 모델 | val667 |
|---|---|
| **27B LoRA** | **646/667 = 0.9685** |
| 35B zero-shot read+tiles | 644 = 0.9655 |
| 397B zero-shot | 643 = 0.9640 |
| **A안 35B LoRA** | **633 = 0.9490** |

| 비교 | Δ | 95% CI | 판정 |
|---|---|---|---|
| A안 − 27B LoRA | −1.95%p | −3.45 ~ −0.60 | **유의** |
| A안 − 35B zero-shot | −1.65%p | −3.00 ~ −0.30 | **유의** |
| A안 − 397B zero-shot | −1.50%p | −3.00 ~ +0.00 | 잡음 |

## 해석 — active 파라미터가 총 파라미터보다 중요하다

같은 패턴이 세 번째 재현됐다.

| 시점 | 비교 | 결과 |
|---|---|---|
| 09/21 zero-shot | 35B MoE vs 27B dense | 0.9445 vs **0.9550** |
| 09/23 zero-shot (n=6,047) | 35B vs 397B | 5,836 = 5,836 (동률) |
| **09/23 파인튜닝** | **35B MoE vs 27B dense** | **0.9490 vs 0.9685** |

35B-A3B 는 총 35B 지만 토큰당 **active 3B** 다. dense 27B 를 파인튜닝에서도 못 따라간다. 397B-A17B 가 35B 와 동률인 것도 같은 축으로 읽힌다 — 총량이 아니라 active 크기가 이 과제의 성능을 가른다.

## 한계

- A안 학습셋은 **5,143건**, 27B 는 **6,047건**이었다(홀드아웃을 667→1,500 으로 늘린 탓). 데이터 15% 차이가 불리하게 작용했을 수 있으나 −1.95%p(13문항)를 전부 설명하기는 어렵다.
- 다음 비교를 깨끗하게 하려면 27B 도 같은 5,143건·holdout1500 으로 다시 돌려야 한다.

## 운영 기록 — 중복 실행 사고

원인은 `pkill -f colab_lora_train` 이 **자기 자신(SSH 명령줄)을 먼저 죽여** 실제 학습 프로세스를 못 죽인 것이다. 다음부터는 `pkill -f '[c]olab_lora_train'` 처럼 자기 패턴을 피하거나 콘솔에서 파드를 정지시킨다.
