## 이게 가리키는 것

**우리 단일 최고 모델(27B LoRA)은 아직 타일을 못 받아봤다.** meta.json 의 args 에 `view` 키 자체가 없어 구버전 스크립트의 `full` 로 학습됐다. 35B 에서 타일이 +1.35~1.53%p 였으므로 27B 에도 비슷한 이득이 있다면 상당한 상승 여지가 있다.

다만 27B 는 이미 0.9685 로 높아 남은 여지가 35B(0.9490)보다 작다. 이득이 그대로 옮겨간다고 가정하지 않는다. **R3(27B LoRA + read+tiles + 결함 71건 제외)** 가 이걸 직접 잰다.

## 35B-A3B 에 대한 판단은 유지한다

타일을 줘도 C안 0.9625 는 27B dense LoRA 0.9685 아래다. 같은 입력 형식으로는 아직 비교 못 했으므로 확정은 아니지만, "active 파라미터가 총 파라미터보다 중요하다"는 관측을 뒤집을 근거는 나오지 않았다.
