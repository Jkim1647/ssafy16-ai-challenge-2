dev 라벨링 패킷 {PID}  ({BATCH})
================================

목적: 모델 평가용 "어려운 문제 정답셋"을 184건에서 늘린다. 모델이 헷갈린 문항만 모았다.
      그래서 쉬운 문제는 거의 없다. 애매하면 억지로 고르지 말고 보류하면 된다.

1. 이 폴더(zip을 푼 폴더)에서 index.html 을 Chrome 또는 Edge로 연다. (파이썬·설치 필요 없음)
   - zip 안에서 바로 열지 말고 반드시 먼저 압축을 푼다(그래야 이미지가 보인다).
2. 상단 "작업자"에 이름을 적는다.
3. 이미지를 보고 보기 1~4 중 정답을 고르고, 근거(이미지 속 글자·위치)를 한 줄 적고 Enter.
   - 확실하지 않음 / 답이 두 개 가능 / 질문이 모호  ->  Q (보류) + 이유
   - 글자가 흐려 읽을 수 없음                         ->  W (판독 불가)
   - 이미지 클릭 = 원본 크기, ＋/－ 확대, ⟳ 회전
4. 입력은 브라우저에 자동 저장된다. 창을 닫았다가 다시 열어도 이어진다.
   (같은 PC·같은 브라우저·같은 폴더 위치일 때. 다른 PC로 옮길 땐 CSV 내보내기 -> 불러오기)
5. 다 끝나면 "결과 CSV 내보내기" -> 받은 labels_..._이름.csv 파일 하나만 김진영에게 보낸다.
   중간에 한 번씩 내보내 두면 안전하다.

규칙
- ChatGPT·Claude·모델 답을 참고하지 않는다. 평가용 정답이라 사람 눈으로만 판정한다.
- 원본 dev.csv의 answer1~5 열을 보지 않는다.
- 이 패킷(대회 이미지)은 팀 밖으로 공유하지 않는다.
